# Лабораторна робота № 2. Місія «Кібер-Дієта»

**Рівень:** 3 — багатоетапна збірка зі статичним виконуваним файлом  
**Варіант:** 2  
**Мова програмування:** Rust

## Мета роботи

Зменшити розмір Docker-образу за допомогою багатоетапної збірки та створити мінімальний фінальний образ на основі `scratch`, який містить лише статично скомпонований виконуваний файл програми.

## Хід роботи

1. Створено `Dockerfile.naive` з базовим образом `fedora:40`. У ньому встановлюється Cargo, копіюється код програми та виконується збірка у режимі `release`.
2. Створено багатоступеневий `Dockerfile`. На етапі `build` використовується `rust:1.79`, встановлюється `musl-tools` і додається ціль компіляції `x86_64-unknown-linux-musl`.
3. Програму скомпільовано для `x86_64-unknown-linux-musl`, щоб отримати статично скомпонований виконуваний файл.
4. Фінальний етап використовує `FROM scratch`. Команда `COPY --from=build` копіює до нього лише виконуваний файл `/vtfk-sid`; компілятор та інструменти збірки до фінального образу не потрапляють.
5. Файл `.dockerignore` виключає з контексту збірки каталог `target/`, каталог `.git/` та тимчасові файли.

## Команди

Обидва образи зібрано командами:

```bash
docker build -f Dockerfile.naive -t lab02-naive .
docker build -f Dockerfile -t lab02-ghost .
```

Для перевірки розміру образів, запуску програми та шарів використано:

```bash
docker run --rm lab02-ghost
docker images | grep lab02
docker history lab02-ghost
```

## Результати

Збірка обох Docker-образів завершилася успішно. Команда `docker images` показала такі розміри:

| Образ | Базовий образ | Розмір |
|---|---|---:|
| `lab02-naive` | `fedora:40` | 1,18 GB |
| `lab02-ghost` | `scratch` | 773 kB |

За показаними розмірами фінальний образ приблизно у **1 526 разів менший** за наївний. Зменшення розміру становить приблизно **99,93%**.

У `docker history lab02-ghost` видно, що фінальний образ складається з шару копіювання виконуваного файлу розміром близько **524 kB** та команди `ENTRYPOINT`, яка не додає даних до образу. Це узгоджується з вимогою залишити у фінальному образі тільки виконуваний файл.

## Перевірка запуску

Для перевірки запуску потрібно виконати:

```bash
docker run --rm lab02-ghost
```

Програма має вивести:

```text
Ядро С.І.Д. активне.
```

*Примітка: у наданому фрагменті консолі успішна збірка обох образів і їхні розміри відображені, але рядок виводу команди запуску не видно. Тому результат запуску слід підтвердити окремим виконанням наведеної команди.*

## Висновок

У ході лабораторної роботи створено наївний Docker-образ на базі `fedora:40` та багатоетапний образ із фінальним етапом `scratch`. Для Rust-програми використано ціль `x86_64-unknown-linux-musl`, а до фінального образу скопійовано тільки статично скомпонований виконуваний файл. Згідно з результатами `docker images`, розмір образу вдалося зменшити з **1,18 GB до 773 kB**, тобто приблизно на **99,93%**.
